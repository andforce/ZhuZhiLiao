# App Privacy 填写依据（赛博竹知了 1.0）

## 跟踪

- 是否使用数据跟踪用户：否
- 是否使用第三方广告或分析 SDK：否
- 跟踪域名：无

## 收集的数据

### 产品交互（Product Interaction）

- 收集：是
- 用途：App 功能（App Functionality）
- 是否与用户身份关联：是，与随机匿名玩家 ID 关联
- 是否用于跟踪：否
- 具体内容：应用按批次发送匿名“哇声”次数，用于聚合总数、在线统计和匿名累计排行榜。

### 用户 ID（User ID）

- 收集：是
- 用途：App 功能（App Functionality）
- 是否与用户身份关联：是，数据本身即随机匿名玩家 ID
- 是否用于跟踪：否
- 具体内容：服务器生成随机匿名玩家 ID 和公开短码，用于累计排行榜、自己的名次、身份认证及删除。它不是 iPhone 硬件标识符。

### 粗略位置（Coarse Location）

- 收集：仅用户主动加入“哇声地球”时
- 用途：App 功能（App Functionality）
- 是否与用户身份关联：是，与随机匿名玩家 ID 关联
- 是否用于跟踪：否
- 具体内容：客户端先把位置量化为约 20 公里格网，只上传格网编号；不上传原始精确坐标，不进行后台定位。

## 不收集的数据

- 设备 ID
- 联系信息
- 精确位置
- 健康与健身数据
- 运动传感器原始数据
- 用户内容
- 购买记录
- 搜索历史、浏览历史或诊断信息

## 本地数据

个人“哇声”计数、安全提示是否已读、地球加入状态和上次格网编号保存在本机 UserDefaults；匿名身份令牌保存在本机 Keychain。应用会上传累计“哇声”成绩和用户主动提供的粗略格网，但不上传动作传感器原始数据或原始精确坐标。
